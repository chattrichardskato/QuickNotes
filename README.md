# QuickNotes

A full-stack web application for taking quick notes. Built with Node.js/Express
(backend) and vanilla JavaScript (frontend).

## Video Demo

[Watch the 4-5 minute walkthrough](https://example.com/your-video-link)

## What I Learned

- Building a REST API with Express (GET, POST, DELETE)
- Serving static frontend files from a Node server
- Client-server communication with `fetch()` and JSON
- Basic input validation and XSS prevention on the frontend

## Requirements

- Node.js 18 or newer

```bash
git clone https://github.com/yourname/QuickNotes.git
